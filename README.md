# wrapfile

当前版本提供命令行版本查询，以及为后续加密备份生成密钥文件的 `keygen` 子命令。

## 构建与运行

```sh
cargo build --offline
./target/debug/wrapfile --version
```

输出：

```text
wrapfile 0.1.0
```

## 生成密钥文件

```sh
./target/debug/wrapfile keygen <密钥文件路径>
```

例如：

```sh
./target/debug/wrapfile keygen backup.key
```

成功时输出 `密钥已生成并保存到 backup.key`，并以状态码 0 结束。

### 密钥文件格式

密钥文件是**恰好 32 字节的原始二进制密钥**，由操作系统密码学安全随机源
（经由 `getrandom` 库）生成，不含文本编码、换行、文件头或任何附加内容。
密钥不会显示在终端或日志中，也不能凭文件名或生成时间推算、恢复。

### 安全与失败行为

- 在 Unix 系统上，密钥文件从创建时起权限即为 `0600`（仅当前用户可读写），
  不依赖 umask 等外部设置。
- 目标路径已存在任何文件、目录或符号链接（包括指向不存在位置的悬空链接）时，
  命令拒绝覆盖，以状态码 1 失败，已有对象保持原样。
- 父目录不存在或不可写、随机源不可用、写入未完成等情况同样以状态码 1 报错，
  不会自动创建父目录，也不会留下不完整的密钥文件。
- 缺少路径、参数过多或使用未知选项时，命令显示用法并以状态码 2 结束，不生成文件。

> **注意**：密钥文件是秘密，请妥善保管（例如限制访问、离线备份）。
> 一旦遗失，无法凭文件名或生成时间恢复其中的密钥，使用该密钥加密的
> 备份也将无法解密。
